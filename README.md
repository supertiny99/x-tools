# ✨ 在线工具箱 (Online Tools Collection)

**在线预览地址 / Online Preview:** [https://tools.330283.xyz/](https://tools.330283.xyz/)

基于 **Astro**、**React** 和 **Tailwind CSS** 构建的快捷高效的在线工具集合。所有工具均在浏览器本地运行，无需服务端处理，数据安全有保障。

## 🛠️ 已实现的工具

### 🚀 WebRTC P2P 聊天与文件传输

真正的一对一直连（Peer-to-Peer）在线协同工具。

- **文本聊天**: 端到端加密通讯，消息不经过任何中央服务器
- **文件发送**: 支持直接点对点发送任意文件，拖拽上传
- **安全与私密**: 一切均在浏览器的 WebRTC 数据通道内本地传输

### 🔲 二维码生成与解析

完全在浏览器端运行的二维码工具。

- **生成二维码**: 将文本、网址实时转化为二维码，支持一键下载或复制
- **解析二维码**: 支持图片上传、拖曳文件及从剪贴板粘贴截图（`Ctrl+V` / `Cmd+V`）
- **本地执行**: 依赖纯前端 Canvas 技术，数据不离开浏览器

### 📊 OpenAPI / Swagger 可视化

导入并实时预览 OpenAPI 或 Swagger（JSON/YAML）规范文档。

- **双栏编辑**: 左侧编辑器，右侧实时渲染
- **格式支持**: 同时支持 JSON 和 YAML 格式
- **格式校验**: 实时高亮语法错误和规范问题

### ✍️ 电子签名

在画布上手写签名，完成后保存为图片。

- **自定义样式**: 可调节笔迹颜色与粗细
- **导出格式**: 一键保存为 PNG 或 JPG 图片
- **完全本地**: 数据不上传，安全可靠

### 🌐 网络检测

一键检测当前网络状态。

- **IP 信息**: 公网 IP、运营商、地理位置
- **连接状态**: 连接类型、连通性延迟检测
- **浏览器本地**: 无需后端服务

### 🖼️ 图片处理

纯本地的图片处理工具。

- **格式转换**: 支持 JPG / PNG / WebP 互转
- **压缩裁剪**: 图片压缩、裁剪、缩放
- **文字水印**: 自定义水印文字、位置、透明度

### 🛡️ 文本脱敏

离线脱敏处理，数据零泄露。

- **自动识别**: 手机号、身份证、邮箱、银行卡等敏感信息
- **自定义规则**: 支持正则表达式自定义脱敏规则
- **一键脱敏**: 输入即处理，原文与脱敏结果对照

### 📝 Markdown 预览

粘贴 Markdown 文本，即刻获得美观的实时渲染预览。

- **实时预览**: 左侧编辑，右侧同步渲染
- **GFM 支持**: 表格、任务列表、删除线、代码块
- **三种视图**: 编辑 / 分栏 / 纯预览模式切换

## 🚀 技术栈

- **框架**: [Astro](https://astro.build/) + `@astrojs/react`
- **界面**: React 19 + Tailwind CSS 4
- **WebRTC**: [PeerJS](https://peerjs.com/)
- **Markdown**: react-markdown + remark-gfm
- **图标**: react-icons
- **部署**: Cloudflare Pages

## 💻 本地开发

```sh
# 安装依赖
npm install

# 启动本地开发服务器
npm run dev
```

启动后访问 `http://localhost:4321`，首页展示所有工具入口。

> ⚠️ 本地开发如遇 native 依赖报错，请参考 [.cloudflare-ci.md](.cloudflare-ci.md)。
>
> ⚠️ 如果新增或调整了前端依赖导入，Vite 可能出现 `Outdated Optimize Dep`、页面空白或 hydration 失败。这通常是依赖预构建缓存过期导致的。请先停止当前开发服务器，再执行：
>
> ```sh
> rm -rf node_modules/.vite
> npm run dev
> ```
>
> 如果只是刚改完依赖或 Vite 配置，通常仅重启一次 `npm run dev` 就能恢复。
